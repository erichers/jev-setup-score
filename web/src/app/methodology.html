Methodology

How a score is made.

The number is a logistic probability. Every input is on the score page, and the walk-forward test uses only information that was already known.

The question

For a horizon H of 5, 10, or 20 sessions, the label is whether the close H sessions ahead is higher than the close on the feature day.

forward return = Close(t + H) / Close(t) - 1

label = 1 when forward return > 0, else 0

A feature row at day t uses only bars through t. Later prices never enter the inputs.

The inputs

Thirteen numbers, daily unless noted:

  • Slope of the 20-day average, and slope of the 50-day average.
  • Slope of the 10-week average, from a weekly resample.
  • Alignment of the 20, 50, and 200 day averages.
  • RSI(14), Wilder smoothing.
  • MACD(12, 26, 9) histogram, and the slope of that histogram. The EMA is seeded with a simple average.
  • ATR(14) as a percent of price. Wilder smoothing.
  • Volume versus its 20-day average.
  • Distance from the 20, 50, and 200 day averages.
  • The return over the last 10 sessions.

The model

Each input is standardized on the training rows:

z = (x - mean) / standard deviation

Logistic regression turns those z values into a probability:

P(up) = 1 / (1 + exp(-(intercept + sum of weight * z)))

score = round(P(up) * 100)

Training maximizes an L2-penalized log likelihood with Newton steps. The intercept is not penalized. A weight is the change in log-odds for one standard deviation of that input. The page lists each weight and the log-odds that input adds today.

Walk-forward test

The calendar is split into a train window of 504 sessions and a test window of 63. The window then steps forward. A training row is eligible only when its label bar is strictly before the test window:

featureBarIndex + horizon < testStartBarIndex

Hit rate is the share of test rows whose predicted side matched the label, using 0.5 as the cut. Brier score is the mean squared error of the probability. Both are shown next to the base rate, which is the share of up closes in the same test rows. If the model does not beat that base rate, the page says so.

The equity curve is a separate rule: long when the rounded score is above the threshold, otherwise flat. Trades do not overlap. It is compared with buy and hold on the same ticker.

Where the bars come from

Live daily bars come from Yahoo Finance, adjusted for splits, then from Stooq if Yahoo fails. Stooq bars are not split adjusted. If both fail, or live fetch is off, the app uses the cached files for SPY, QQQ, AAPL, NVDA, TSLA, MSFT, AMZN, GOOGL, META, AMD, JPM, NFLX, AVGO, COST, and WMT. The score page says whether the result used live or cached data.

The examples on the home page are the newest walk-forward prediction for each of those names at a 10-session horizon. The outcome in each line is the forward return that the test already knew.

What this is not

Educational tool. Not financial advice. A score is a model probability on past daily bars. It is not a forecast you should trade, and it is not a promise about the next close.
